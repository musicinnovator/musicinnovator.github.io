Variant selection

Exact, grouped, or randomized.

The desktop UI supports one variant, a selected group, a deterministic random mix, and compatible-family selection. The catalog will continue to grow without losing existing IDs.

User-selected

Pick one exact variant and see its source-derived description before applying it to compatible findings.

Selected set

Highlight a group of variants, then assign one per target with an auditable selection plan.

Seeded random

Choose a seed, record the result, audition it, reject it, and reselect without restarting the application.

More variants are planned for coming ETAPKI versions by Harris Software Solutions, LLC (Roderick D. Harris, Sr.).
