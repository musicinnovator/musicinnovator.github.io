Overview / Docs
A transparent workflow

Plain-language trust gates.

ETAPKI is a standalone desktop tool. The public site explains the workflow without requiring an account, collecting a file, or hiding technical decisions behind marketing language.

Product flow

Import → understand → audition → export.

Every stage is visible and reversible.

1

Import

Validate the MIDI header, tracks, timing, event bounds, and source checksum. Keep the original read-only.

2

Analyze

Select locations, review evidence and confidence, and inspect compatible embellishment families.

3

Revise

Choose exact or random variants, preview before/after, reject or reselect, and retain an audit trail.

Integrity gate

Nothing is called finished early.

The application exports a new file only after the candidate revision passes structural checks and can be reopened by the project parser.

GateWhat it protectsPresentation state
Source checksumDetects source changes during the session.Source locked / unchanged
Model validationChecks notes, durations, channels, ticks, and event relationships.Revision valid / needs review
SerializerWrites a new format 0 or format 1 MIDI output.Writing candidate
Re-openConfirms the output is readable by the project parser and structurally comparable.Readable / failed
External checkProvides an additional readability confidence check when available.Exportable / held

Backend stays backend

The user sees descriptions, evidence, compatibility, and recovery guidance. Raw source paths, dispatch names, registry statuses, and formula internals remain in developer reports.
