# ETAPKI website

This is the isolated static ETAPKI presentation site. It uses the UIUX concept
board and verified ETAPKI workflow as source material. It does not modify or
depend on any other project or website.

Pages:

- `index.html` — overview and visual direction
- `workspace.html` — interactive presentation prototype
- `transformations.html` — seven embellishment families
- `analysis.html` — analysis locations and compatibility
- `timeline.html` — preview and source/revision comparison
- `documentation.html` — workflow and integrity gates

The prototype is intentionally static. The C++ desktop application remains the
source of truth for MIDI parsing, analysis, transformation formulas, preview,
revision, and export.
